# Gym Tracker
A simple Python-based Gym Tracker

## Features
- Add Workouts
- View Workout History
- Save Workouts using JSON
- Track Workout Dates

## How It Works
Users can enter:
- Exercise name
- Weights lifted
- Number of reps
- Workout Date
The workout data is stored in a JSON file and can be viewed later.

## Technologies Used
- Python
- JSON
- Git & GitHub
